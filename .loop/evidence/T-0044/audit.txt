## 7. A second finding, fixed after the first battery run

**The CLI must not invent a configuration default the daemon does not have.** The first version of
`machines` fell back to `$XDG_CONFIG_HOME/arreo/arreo.toml` when neither `--config` nor `$ARREO_CONFIG`
was given; the daemon reads `--config`/`$ARREO_CONFIG` and nothing else (T-0051). That is one fact —
"which file is this machine's relay configuration" — with two sources, the defect class this project
has hit six times. Removed, with the reason in the code:

  no path named  -> exit 2, naming both --config and ARREO_CONFIG
  a path named, but no [relay] section (or the file is gone, or enabled = false)
                 -> exit 4, naming the file it read

vet 336 exempted; deny 4/4; audit 0 advisories; check-targets PASS/SKIP; 8 slices green; bench 6/6.
