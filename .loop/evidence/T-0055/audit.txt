# T-0055 evidence — a machine that was away for weeks reattaches in seconds

The absence is simulated by moving the relay's clock across a restart
(`ARREO_CLOCK_OFFSET_MS`), not by sleeping: a real fifteen-day wait is not a
test, and a short TTL with a real sleep is worse than either — slow, and still
not the window it claims to exercise. The offset is read once, so every clock
read in a run shifts together.
