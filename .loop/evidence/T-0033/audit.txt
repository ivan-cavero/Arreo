# T-0033 evidence — the machine audit trail

Every command below was run against the final code on this turn. The scenario
output comes from a real `arreo-server` on a real socket (the probe directory is
`/tmp/auditprobe2`, torn down afterwards); the test runs are the acceptance
tests that ship with the task.

## 1. The trail, end to end (a real daemon, the real CLI)

### setup: a fresh daemon on /tmp/auditprobe2/s.sock (identity dir /tmp/auditprobe2)
$ ARREO_IDENTITY_DIR=/tmp/auditprobe2 arreo-server --socket /tmp/auditprobe2/s.sock

### 1. the scripted sequence: spawn -> send (with a live secret) -> attach

$ arreo send pane-a 'export GITHUB_TOKEN=ghp_AAAABBBBCCCCDDDDEEEEFFFF'
$ arreo send pane-a 'echo hello'
