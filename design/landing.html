Machines

Your VPS and your Raspberry Pi, one herd.

Run a server on each machine and they appear as one fleet. Attach to any of them from any of them — or from the phone, or the web. Pair with a code; no SSH, no ports.

$ arreo machines
● workbox VPS · online · 12 agents · 2 asking
● raspberry RPi 5 · online · 8 agents · 0 asking
○ laptop MacBook Pro · offline · last seen 3 h ago
$ arreo attach raspberry # from the VPS, E2E, zero config
Fleet ops

Things you shouldn't have to think about, handled.

config sync

Edit a provider once

Add a provider to opencode.jsonc on the VPS and it replicates to every machine — version vectors, conflict copies, secrets never leave the keychain.

updates

Updated without a cut

The new daemon inherits every PTY from the old one, live. If the handoff fails, the old daemon keeps serving. Agents never die; clients reattach in seconds.

resilience

Two weeks offline, fine

The relay queues everything — encrypted, 30 days — and device certs don't expire by age. Power it back on and the herd resumes like nothing happened.

security

Zero inbound ports

The daemon binds localhost only. All remote access is outbound QUIC with Noise-KK device certs. The relay stores ciphertext it cannot read.

resources

RAM, per agent, enforced

Live meters everywhere; hard caps via cgroups / Job Objects. A hungry agent gets throttled — and you get told.

plugins

Sandboxed UI extensions

WASM components with capability manifests: sidebar widgets, badges, custom panes, commands. Hot-loaded, throttled if misbehaving, never trusted with the render loop.
